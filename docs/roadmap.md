# Roadmap

Near-term milestones:

1. Complete the real Forge game bridge.
2. Run reproducible Commander games through `ForgeEngine`.
3. Add richer matchup and seat-position analysis.
4. Add stronger heuristic and LLM-backed player policies.
5. Add deck mutation and A/B experimentation loops.
6. Add a faster screening engine for large candidate populations.

Longer term, the same decision layer can support learned policies, self-play datasets, deck optimization, and multimodal play assistance.
